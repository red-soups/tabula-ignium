# 지구본 영상 출처

지구본 미리보기는 [FireScope 저장소](https://github.com/red-soups/firescope)의 텍스처 생성 결과를 사용합니다.

- `earth-day.jpg`: Sentinel-2 cloudless 2024 © EOX IT Services GmbH. Contains modified Copernicus Sentinel data 2024. CC BY-NC-SA 4.0.
- `earth-night.jpg`: NASA GIBS VIIRS Black Marble 2016.
- `earth-water.jpg`: NASA GIBS OSM Land/Water Map에서 만든 바다 마스크.
- `earth-clouds.jpg`: NASA Visible Earth Blue Marble 구름 합성.

낮 영상에는 비상업적 이용 조건이 있으므로 상업 배포 전 별도 사용 허가 또는 대체 영상을 확인해야 합니다. 시연 화재 좌표는 `src/data/mockFireLocations.ts`의 가상 데이터입니다.
